# CodeAlpha Image Gallery

A responsive Image Gallery project developed as part of the CodeAlpha Frontend Development Internship.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Project Structure

```text
ImageGallery/
│
├── assets/
│   └── images/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## Features

* Image gallery interface
* Responsive layout
* Interactive functionality using JavaScript
* Styled using custom CSS

## Getting Started

1. Clone this repository:

   `git clone https://github.com/ravindrrazput/CodeAlpha_ImageGallery.git`

2. Open the project folder.

3. Open `index.html` in your browser.

## Technologies

This project uses vanilla JavaScript without external frontend frameworks.
